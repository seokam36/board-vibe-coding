# 화면 디자인 기준 (UI1)

화면을 고칠 때 이 파일의 색·글꼴·간격만 쓴다. 새 색이 필요하면 여기에 먼저 이름을 붙인다.

## 무엇을 위한 화면인가
- 대상: 한국 대학에 다니는 외국인 유학생. 폰으로 자주 들어온다.
- 하는 일: 같은 학교 선배가 남긴 글을 빨리 훑고, 질문하고, 답을 단다.
- 느낌: 학교 게시판처럼 **촘촘한 목록**(에브리타임처럼 깔끔하게). 단, 빨간 포인트·그 앱의 생김새는 쓰지 않는다.
- **항상 밝은 화면**(여권 남색 글자 + 노랑 포인트, 연한 회청 바탕). 어두운 화면·전환 버튼은 없다.

## 한 가지 기억에 남을 것
**게시판 이름이 크게 바뀌는 머리말.** 학교를 고르면 머리말이 "전체 게시판"에서 "경희대학교"로 크게 바뀐다. 굵고 큰 글자는 이것과 비자 일정 화면의 D-n(아래 "비자 일정 D-n") 둘뿐이고, 나머지는 조용하게 둔다.

## 색 (앱 `app_colors.dart`)
여권 남색을 글자·주요 버튼에, 노랑을 포인트(바탕)에 쓰는 **밝은 팔레트**다(S26-b). 색 숫자는 앱의 `lib/theme/app_colors.dart`가 원본이고, 모든 값이 서로 다르다(테스트가 어느 토큰을 썼는지 구분하려고). 글자·바탕 짝의 대비는 `test/color_contrast_test.dart`가 4.5:1 이상인지 계산한다.

|---|---|---|
| `canvas` | `#F4F6FA` | 판 바깥 바탕(연한 회청) |
| `paper` | `#FFFFFF` | 목록·글·폼이 놓이는 판, 상단바 |
| `ink` | `#1C2B4F` | 본문 글자(여권 남색), **주요 버튼 바탕**(글자는 흰색) |
| `muted` | `#5B6782` | 작성자·날짜·보조 글자 |

보조 토큰: 툴팁은 `ink` 바탕 + 흰 글자, 비활성 주요 버튼은 `ink` 60% 바탕 + 흰 글자. `dangerStrong` `#7A1712`(위험 버튼을 누르고 있을 때 바탕, 글자 흰색), `dangerSoft` `#FCE8E6`(에러 안내 배경), `successInk` / `successSoft` `#1E6B45` / `#E3F3EA`(성공 안내. 정보 안내와 구분되게 초록), `infoSoft` `#E8EEF6`(정보 안내 배경), `backdrop` 검정 45%(확인 창 뒤를 덮는 막), 뱃지: 잡담·거래완료 `badgeChatBg` `#EEF1F6`(글자 `muted`), 질문·예약중 `badgeQuestionInk` / `badgeQuestionBg` `#0F5E66` / `#DDF1F2`. 웹은 `theme-color`(index.html)와 manifest의 `theme_color`·`background_color`가 모두 `canvas` 값(상단 띠가 화면 바탕과 이어진다). 안드로이드 상태 표시줄·내비게이션 바는 `canvas` 바탕 + 어두운 아이콘(`app.dart`의 `darkSystemIcons`).

날짜는 초를 빼고 "11월 8일 15:19"로 짧게(올해가 아니면 연도를 붙인다).
날짜만 있는 값(접수일·결과일)은 연도를 붙여 "2026년 9월 1일"로(`formatDay`, 시간대 영향이 없게 문자열을 직접 쪼갠다).

쪽지함 안 읽은 수 배지(`.badge-unread`): 상대 닉네임 옆, 인증 뱃지와 같은 파랑(`accentInk` / `accentSoft`). 100 이상은 "99+"로 줄이고, 화면 읽기 프로그램에는 "안 읽은 쪽지 N개"로 읽힌다(`.sr-only`). 새 색 없음.
인증 뱃지(`.badge-verified`): 학교 인증을 마친 회원 표시(상단바 "인증", 내 정보 "유학생 인증 완료 · 학교명"). 파랑(`accentInk` / `accentSoft`).

결과 뱃지(`.badge-result-APPROVED` / `.badge-result-DENIED`): 승인은 인증 뱃지와 같은 파랑(`accentInk` / `accentSoft`), 불허는 잡담 뱃지와 같은 회색(`muted` / `badgeChatBg`). 빨강은 쓰지 않는다(위험색은 되돌릴 수 없는 동작에만).

표(`.stats-table`, 비자 후기 통계): 판 안, 머리글 `muted` 13px, 행 사이 `line`, 숫자 열은 오른쪽 정렬, 소수는 항상 1자리("19.0일"). 표 wrapper만 가로 스크롤. 링크 탭(`.tabs a`)의 현재 탭은 `aria-current="page"`(파랑 밑줄).

비자 일정 D-n(`.visa-dday`, /visa-plan): 머리말과 같은 30px·700. 이 화면의 핵심 숫자라 키운 예외다. 색은 평소 `ink`, CHECK·URGENT(30일 이내)는 파랑 `accent`, EXPIRED(지남)는 `muted`. 빨강은 쓰지 않는다. 할 일 목록(`.visa-todo`)의 날짜는 마감이 아니라 "확인을 시작할 시점"이라, 줄에는 D-n 대신 굵은 칸 "만료 120일 전부터"와 날짜 "2026년 7월 29일"(부터 없음)을 쓴다(위 큰 D-n과 기준이 다른 D 숫자를 섞지 않는다. 굵은 칸 min-width 8.5em으로 날짜 시작 위치를 맞춘다). 상태는 날짜 옆 글자 네 가지로도 알린다(색만으로 알리지 않는다): 지금 단계(stage와 같은 줄)는 "지금 확인할 때" + 굵은 칸과 상태 글자를 `accent`(상태 글자는 굵기 500)으로 강조, 아직 안 온 줄은 "n일 뒤 시작"(보통 색), "오늘 시작"(서버 규칙상 도달 불가, 모르는 stage 대비), 이미 지난 단계는 "지난 단계" + 흐리게(`muted`).

상단 비자 일정 띠(`.visa-banner`): 상단바 바로 아래 한 줄, 로그인한 인증 회원 화면에서만 뜨고 /visa-plan에서는 숨긴다. `infoSoft` 배경 + `ink` 글자 14px, 빨강은 쓰지 않는다. 닫기 버튼(×)은 눌리는 영역 40px, 글리프는 17px(글꼴 단계표 값). 375px에서는 문구·링크가 줄바꿈된다.

물건 글 상태 뱃지(`.badge-ON_SALE` / `.badge-RESERVED` / `.badge-DONE`): 판매중은 파랑(`accentInk` / `accentSoft`), 예약중은 질문 말머리와 같은 청록(`badgeQuestionInk` / `badgeQuestionBg`), 거래완료는 잡담 뱃지와 같은 회색(`muted` / `badgeChatBg`). 빨강은 쓰지 않는다.
신고 대상 뱃지(`.badge-POST` / `.badge-COMMENT` / `.badge-MARKET_ITEM` / `.badge-CONVERSATION`): 글은 파랑, 댓글은 잡담 뱃지와 같은 회색, 중고 글("중고")은 질문 말머리와 같은 청록(`badgeQuestionInk` / `badgeQuestionBg`), 대화("쪽지")는 파랑 글자 + `hover` 배경(새 색 없음). 빨강은 쓰지 않는다.

사진(중고 글): 목록 썸네일(`.market-thumb`)은 72px 정사각·`object-fit: cover`, 모서리 `--radius-btn`. 상세 큰 사진은 폭 100%·4:3 고정 틀(`.market-photo-frame`)에 `object-fit: contain`(비율이 달라도 아래 썸네일 줄이 움직이지 않는다), 틀 배경 `--canvas`. 상세 썸네일 버튼(`.market-photo-thumb`)은 56px 정사각·cover, 고른 것은 `accent` 테두리. 사진이 없거나 못 불러온 썸네일 빈칸은 `hover` 회색, 큰 사진 실패 문구("사진을 불러오지 못했습니다")는 틀 안 가운데 `muted` 14px.
글쓰기·수정의 사진 올리기 영역(`.market-photo-picker`): `.panel` 안에 "사진 (n/10)" 제목, 72px 정사각 미리보기(`.market-photo-preview`, cover, `--radius-btn`, 빈칸 `hover`)와 그 아래 `btn btn-sm`(수정 "삭제"·글쓰기 "빼기")를 `--space-3` 간격으로 줄바꿈하며 나열한다(375px에서 가로 스크롤 없음). [사진 추가]는 `btn` 버튼이 숨긴 `input[type=file]`을 대신 열고, 진행("사진 올리는 중 n/전체")은 info 안내(role=status), 사전 검사·서버 에러는 error 안내(role=alert). 10장이면 추가 버튼을 비활성하고 옆에 `meta` 안내를 둔다.

쪽지(`/messages`, `/messages/:id`, S14-d): 쪽지함은 판 하나 안의 행들(`.conv-row`). 한 줄 = 상대 닉네임(17px·500) + 시각(오른쪽, `meta`) / 글 제목(`meta`, 지워진 글은 회색 "삭제된 글" 뱃지) / 마지막 쪽지 한 줄(길면 줄임표, 내가 보낸 것은 "나: "). 줄 전체가 링크이고 마우스를 올리면 `hover` 배경. 대화 화면의 말풍선(`.msg-bubble`)은 내가 보낸 것이 오른쪽 `accent-soft` 배경 + `accent-ink` 글자, 상대가 보낸 것이 왼쪽 `hover` 배경 + `ink` 글자(폭 최대 85%, 모서리 `--radius-panel`), 시각은 말풍선 아래 `muted` 13px. 쪽지함 줄에는 닉네임 옆에 안 읽은 수 배지(`.badge-unread`, 파랑 accentInk / accentSoft)가 붙고, 대화 화면은 hasMore면 목록 위에 회색 안내 한 줄(`muted`, 작은 글씨)을 둔다. 쪽지 쓰는 칸(`.message-form`)은 textarea 아래에 글자 수("0 / 1000", `muted`)와 `btn-primary`. 새 색 없음.

말머리 뱃지(글자색 / 배경): 잡담 `muted` / `#EEF1F6`, 질문 `#0F5E66` / `#DDF1F2`, 학교생활 `highlightInk` / `highlightSoft`(노랑 계열).

## 아래 탭 막대와 위 막대 (S26-c)
- **아래 탭 막대**(`BottomTabs`): 모든 화면 맨 아래에 탭 5개, 순서는 게시판 `/` · 비자 `/visa-reviews` · 중고 `/market` · 쪽지 `/messages` · 내 정보 `/me`. 비로그인도 똑같이 5개(쪽지·내 정보를 누르면 기존 문지기가 /login으로 보낸다). 막대 바탕 `paper` + 위쪽 `line` 선 하나, 그림자 없음. 바탕은 화면 끝까지, 안쪽 5칸은 본문 폭 720 가운데에 모은다.
- 한 칸 = Material 아이콘(24) + 글자(13). 눌리는 영역은 가로·세로 48 이상(높이 56). 선택된 탭은 `accent` 색 + 굵은 글자 + 채운 아이콘 + 스크린리더 selected(색만으로 알리지 않는다), 안 고른 탭은 `muted` 글자 + 테두리 아이콘.
- 선택은 주소의 첫 마디로 정한다: `/`·`/posts/…`→게시판, `/visa-reviews…`·`/visa-plan`→비자, `/market…`·`/chat`→중고, `/messages…`→쪽지, `/me`·`/admin/…`·`/login`·`/signup`→내 정보, 그 밖(404)→선택 없음.
- 쪽지 탭 배지: 안 읽은 수가 1 이상이면 `highlight` 노랑 동그라미에 `ink` 숫자(100 이상은 "99+", 스크린리더는 "쪽지, 안 읽은 쪽지 N개"), 0이면 숫자 없음. 숫자는 위 막대가 쓰던 같은 보관소(UnreadStore)에서 받아 요청이 늘지 않는다.
- 키보드가 올라오면(viewInsets 아래쪽 > 0이라 키보드가 뜨는 모바일 웹도 포함) 탭 막대는 숨긴다. Scaffold는 아래 막대를 키보드 위로 올려 주지 않아 막대가 키보드 뒤에 반쯤 걸치고 본문만 줄어들기 때문이다. 폰 아래 제스처 막대 여백은 앱 전체 SafeArea가 처리한다. 탭 글자는 기기 글자 크기를 키워도 1.3배까지만 커진다(칸 높이 56 유지).
- **위 막대**(`NavBar`)는 얇은 한 줄: 왼쪽 사이트 이름(`accent`), 오른쪽에 비로그인이면 "로그인"·"회원가입", 로그인이면 "챗봇"·"{닉네임} 님"·인증 뱃지·"로그아웃". 375px에서 인증 회원(닉네임 4글자)도 한 줄. 탭으로 옮긴 링크와 비자 일정·관리자 메뉴는 여기에 없다.
- 탭에서 빠진 **비자 일정**(인증 회원만)과 **신고 관리·인증 심사**(관리자만)는 내 정보 화면 제목 바로 아래 바로가기 줄에 둔다.

## 글꼴
- **IBM Plex Sans KR** (Google Fonts, 400·500·700) 하나만 쓴다. 한글과 영문의 폭이 고르게 맞아서, 한국어·영어가 섞이는 유학생 글에 맞다. 불러오지 못하면 시스템 글꼴.
- 크기: 13(보조) / 14(메뉴·작은 버튼·라벨·안내) / 15(본문) / 17(목록 제목) / 22(글 제목) / 30(게시판 머리말).
- 굵기: 본문 400, 목록 제목 500, 머리말·글 제목 700.
- 줄 길이는 판 폭(최대 720px)으로 80자 안쪽, 본문 줄 간격 1.65.

## 배치
```text
┌ 상단바 (판 색, 아래 선 한 줄) ───────────────────────┐
│ 사이트이름(파랑 accent 글자)         챗봇  홍길동 님  로그아웃 │
└────────────────────────────────────────────────────┘
  경희대학교                      ← 게시판 머리말 (30px, 700)
  [전체 학교 ▾] [전체 말머리 ▾]          [글쓰기]
┌ 판 (paper) ─────────────────────────────────────────┐
│ 질문  비자 연장은 언제부터 신청하나요?              │ ← 한 행, 아래 선
│ 선배A   11월 8일   댓글 3   공감 5                  │
├────────────────────────────────────────────────────┤
│ 잡담  기숙사 근처 맛집                              │
└────────────────────────────────────────────────────┘
```
- 글 목록은 **카드 여러 장이 아니라 판 하나 안의 행**들(선으로 구분). 그림자 없음.
- 왼쪽 정렬. 가운데 정렬은 로그인·가입 폼 카드에만.
- 모서리: 판·입력칸 8px, 뱃지 4px, 버튼 6px. 크기가 다르면 모서리도 다르다.
- 메타 정보(작성자·날짜·댓글·공감)는 가운뎃점(·) 대신 간격으로 나눈다.
- 확인 창: 브라우저 기본 창 대신 공용 `<dialog>` 하나(`useConfirm`). 왼쪽 "취소"(처음 포커스), 오른쪽은 동작 이름 그대로("삭제", "탈퇴"), 되돌릴 수 없는 동작이면 위험색. 화면이 바뀌면 취소로 닫힌다.

## 하지 않는 것
- 카드마다 같은 그림자·같은 모서리, 그라데이션 장식
- 모두 대문자 라벨, 제목 위 작은 꼬리표, 링크 뒤 화살표(→)
- 크림색 바탕 + 주황/테라코타 포인트, 검정 바탕 + 형광 포인트(이번 바탕은 연한 회청+남색 글자+노랑 포인트라 해당 안 됨)
- 등장 애니메이션. 움직임은 누른 버튼의 상태 변화(공감 켜짐 등)에만, `prefers-reduced-motion`이면 끈다

## 기본 품질
- 375px 폭에서 가로 스크롤 없음, 버튼 높이 40px 안팎
- 입력칸 포커스는 테두리가 파랑(accent 1px)으로 바뀐다. 버튼·링크는 Material 기본 포커스 덧칠을 쓴다
- 글자 대비 4.5:1 이상 (`muted`도 판·바탕 위에서 통과하는 값)
- `role="alert"`, `aria-label`, `aria-pressed`는 지우지 않는다
