# 화면 디자인 기준

Flutter 앱(`flutter_app/lib`)의 색·글꼴·간격·부품 기준이다. 숫자의 원본은 `theme/app_colors.dart`(`AppColors`·`AppSizes`)와 `theme/app_theme.dart`이고, 이 문서는 그 뜻과 쓰는 곳을 적는다. 새 색이 필요하면 여기에 먼저 이름을 붙인다.

## 1. 원칙
- 대상: 한국 대학에 다니는 외국인 유학생. 폰으로 자주 들어와 같은 학교 선배의 글을 빨리 훑고, 질문하고, 답을 단다. 학교 게시판처럼 **촘촘한 목록**(깔끔하게, 다른 앱의 빨간 포인트·생김새는 쓰지 않는다).
- **항상 밝은 화면**: 여권 남색 글자 + 노랑 포인트, 연한 회청 바탕. 어두운 화면·전환 버튼은 없다.
- **노랑(`highlight`)은 바탕으로만** 쓰고 글자색으로 쓰지 않는다. 노랑 위엔 `ink` 글자만.
- **파랑(`accent`)은 선택·링크·포커스**를 알릴 때만 쓴다.
- **대담함은 머리말 하나**: 굵고 큰 30px 글자는 목록 머리말(게시판은 학교를 고르면 "전체 게시판"→"경희대학교"로 바뀐다)과 비자 일정의 D-n뿐이고, 나머지는 조용하게 둔다.
- 색만으로 상태를 알리지 않는다(체크 아이콘·굵은 글자·글자 문구를 같이 쓴다). 빨강(`danger`)은 삭제·탈퇴처럼 되돌릴 수 없는 동작과 에러에만 쓴다.
- 하지 않는 것(AI 티 나는 기본값): 카드마다 같은 그림자·모서리, 그라데이션 장식, 모두 대문자 라벨, 제목 위 작은 꼬리표, 링크 뒤 화살표(→), 크림 바탕+주황 포인트, 검정 바탕+형광 포인트, 등장 애니메이션(화면 전환 효과도 꺼 두었다. 움직임은 누른 버튼의 상태 변화에만).

## 2. 색 (`AppColors`)
모든 값이 서로 다르다(어느 토큰을 썼는지 테스트가 구분하려고). 글자·바탕 짝은 4.5:1 이상, 입력칸·버튼 테두리(`fieldBorder`)는 흰 바탕·`canvas`와 3:1 이상이어야 하고, `test/color_contrast_test.dart`가 계산한다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `canvas` | `#F4F6FA` | 판 바깥 바탕(연한 회청). 웹 `theme-color`·manifest·안드로이드 상태 표시줄도 이 값 |
| `paper` | `#FFFFFF` | 목록·글·폼이 놓이는 판, 위 막대, 아래 탭 막대 |
| `ink` | `#1C2B4F` | 본문 글자(여권 남색), **주요 버튼 바탕**(글자 흰색), 고른 칩 바탕, 툴팁 바탕 |
| `muted` | `#5B6782` | 작성자·날짜·보조 글자, 안 고른 탭 |
| `line` | `#E3E8F2` | 판 테두리·행 사이 선 같은 장식 선 |
| `fieldBorder` | `#7F8AA3` | 입력칸·선택 상자·보통 버튼 테두리(`line`은 너무 옅어 칸이 안 보인다) |
| `hover` | `#EBEFF6` | 마우스를 올렸을 때·눌렀을 때 바탕, 상대 말풍선, 이니셜 빈 칸 |
| `accent` | `#2450B8` | 링크, 선택된 탭, 사이트 이름, 입력칸 포커스 테두리 |
| `accentSoft` / `accentInk` | `#E4EAF8` / `#1D3F94` | 눌린 공감, 인증·승인·판매중 뱃지, 내 말풍선, 안 읽은 쪽지 수(쪽지함 줄) |
| `highlight` | `#F2B705` | 노랑 포인트(바탕 전용): 글쓰기 연필 버튼, 아래 탭 쪽지 배지 |
| `highlightSoft` / `highlightInk` | `#FCEBB0` / `#5C4500` | 학교생활 말머리 뱃지, 이니셜 동그라미 |
| `badgeChatBg` | `#EEF1F6` | 잡담·거래완료 뱃지 배경(글자 `muted`) |

| `danger` | `#B3261E` | 삭제·탈퇴 버튼 글자·선, 에러 안내 글자 |
| `dangerStrong` | `#7A1712` | 위험 버튼을 누르는 동안 바탕(글자 흰색) |
| `dangerSoft` | `#FCE8E6` | 에러 안내 배경, 위험 버튼 hover 바탕 |
| `successInk` / `successSoft` | `#1E6B45` / `#E3F3EA` | 성공 안내(정보 안내와 구분되게 초록) |
| `infoSoft` | `#E8EEF6` | 정보 안내 배경, 비자 일정 띠 배경 |
| `backdrop` | 검정 45% | 확인 창 뒤를 덮는 막 |

- 비활성 주요 버튼: `ink` 60% 바탕 + 흰 글자(글자는 비활성이어도 흰색). 안드로이드 상태 표시줄은 `canvas`(위 막대가 본문과 같이 스크롤되어 올라가면 canvas 본문 바탕이 비친다), 내비게이션 바와 아래 안전 영역 띠는 흰 아래 탭 막대와 이어지게 `paper`, 아이콘은 어둡게(`app.dart`의 `darkSystemIcons`·`safe`).
- 날짜는 초를 빼고 "11월 8일 15:19"(올해가 아니면 연도를 붙인다, `formatDate`). 날짜만 있는 값(접수일·결과일)은 "2026년 9월 1일"(`formatDay`, 시간대 영향이 없게 문자열을 직접 쪼갠다).

## 3. 글꼴
- **IBM Plex Sans KR** 하나만 쓴다(`pubspec.yaml`에 400·700 두 파일을 번들하고, 엔진이 구글에서 Roboto를 받지 않게 family 이름만 `Roboto`로 등록). 한글·영문 폭이 고르게 맞아 한국어·영어가 섞이는 글에 좋다.
- 크기(`AppSizes.fs…`)와 쓰는 곳:

| 크기 | 이름 | 쓰는 곳 |
|---|---|---|
| 13 | `fsSmall` | 보조 글자(시각·댓글 수), 뱃지, 아래 탭 글자, 조용한 [신고] |
| 14 | `fsSmall2` | 메뉴, 버튼, 라벨, 안내, 칩, 피드 줄의 닉네임 |
| 15 | `fsBody` | 본문, 글 보기의 닉네임, 글·댓글 입력칸 |
| 16 | `fsFeedTitle` | 글 목록·비자 후기·중고 목록(피드형) 줄의 제목, 쪽지함 줄의 상대 닉네임 |
| 17 | `fsRow` | 챗봇 참고 글 제목(`RowLink`), 사이트 이름, 확인 창 제목 |
| 22 | `fsTitle` | 화면 제목(`PageTitle`), 글 제목 |
| 30 | `fsBoard` | 목록 머리말(게시판·비자 후기·중고), 비자 일정 D-n |

- 굵기: 본문 400, 굵게 700(머리말·화면 제목·글 제목·피드 제목·닉네임·고른 탭·고른 칩). 코드에 500도 쓰이지만(뱃지·라벨·안 고른 칩·챗봇 참고 글 제목) 번들한 파일이 없어 400에 가깝게 그려진다.
- 줄 간격: 본문 1.65(`AppSizes.bodyLineHeight`, 글 보기·댓글 본문, 글·댓글 입력칸, 중고·비자 후기 본문이 같이 쓴다), 안내·피드 제목 1.5. 줄 길이는 판 폭(최대 720)으로 80자 안쪽.

## 4. 간격·모서리
- 간격 `space1~5` = 4 / 8 / 12 / 16 / 24. 본문 폭 `pageMaxWidth` 720(가운데), 좌우 여백 16, 위아래 24.
- 모서리: 판·입력칸·안내 8(`radiusPanel`), 버튼 6(`radiusBtn`), 뱃지 4, 칩은 알약, 이니셜·연필 버튼은 동그라미. 크기가 다르면 모서리도 다르다.
- 판(`Panel`): `paper` 바탕 + `line` 테두리 + 안쪽 16, 그림자 없음. `FlushPanel`은 안쪽 여백 없이 행·표가 테두리까지 닿는다.
- 왼쪽 정렬. 가운데 정렬은 로그인·가입 폼 카드에만. 메타 정보(작성자·날짜·댓글·공감)는 가운뎃점 대신 간격·굵기·뱃지로 나눈다.

## 5. 공통 틀
```text
┌ 위 막대 (paper, 아래 line 선, 본문과 같이 스크롤) ──────┐
│ 사이트이름(accent)              챗봇  홍길동 님 [인증] 로그아웃 │
└──────────────────────────────────────────────┘
  (인증 회원이면 비자 일정 띠 한 줄: infoSoft)
  ┌ 본문 기둥 (최대 720, 가운데) ───────────────┐
  │ 화면 내용                                    │
  └──────────────────────────────────────────┘
                                      (연필)    ← 게시판·비자 후기·중고 목록에서, 탭 막대 바로 위
┌ 아래 탭 막대 (paper, 위 line 선, 고정) ──────────────┐
│  게시판   비자    중고    쪽지    내 정보              │
└──────────────────────────────────────────────┘
```
- **위 막대**(`NavBar`): 얇은 한 줄. 왼쪽 사이트 이름(홈 링크, `accent` 17·700), 오른쪽에 비로그인이면 "로그인"·"회원가입", 로그인이면 "챗봇"·"{닉네임} 님"·인증 뱃지·"로그아웃". 375px에서 인증 회원(닉네임 4글자)도 한 줄이고 더 좁으면 줄바꿈. 로그아웃 실패 안내는 줄 아래. 글자 시작선은 본문 기둥과 맞춘다. 비자 일정(인증 회원만)과 신고 관리·인증 심사(관리자만)는 위 막대가 아니라 내 정보 화면 바로가기로 갔다.
- **아래 탭 막대**(`BottomTabs`): 모든 화면 맨 아래 고정. 탭 5개, 순서 게시판 `/` · 비자 `/visa-reviews` · 중고 `/market` · 쪽지 `/messages` · 내 정보 `/me`. 비로그인도 똑같이 5개(쪽지·내 정보는 문지기가 /login으로 보낸다). 막대 바탕과 선은 화면 끝까지, 안쪽 5칸은 720 가운데에 모은다. `Scaffold.bottomNavigationBar`라 본문은 그 위 남은 자리에만 그려진다.
  - 한 칸 = Material 아이콘 24 + 글자 13, 눌리는 영역 가로 화면/5 × 세로 56.
  - **선택 표시**: 고른 탭은 `accent` + 굵은 글자 + 채운 아이콘 + 스크린리더 selected, 안 고른 탭은 `muted` + 테두리 아이콘. 선택은 주소의 첫 마디로 정한다(`tabIndexFor`): `/`·`/posts/…`→게시판, `/visa-reviews…`·`/visa-plan`→비자, `/market…`·`/chat`→중고, `/messages…`→쪽지, `/me`·`/admin/…`·`/login`·`/signup`→내 정보, 그 밖(404)→선택 없음.
  - 쪽지 탭 배지: 안 읽은 수가 1 이상이면 `highlight` 동그라미에 `ink` 숫자(100 이상 "99+", 스크린리더는 "쪽지, 안 읽은 쪽지 N개"), 0이면 없음. 숫자는 `UnreadStore`에서 받아 요청이 늘지 않는다.
  - **키보드 숨김**: 키보드가 올라오면(`viewInsets.bottom > 0`, 모바일 웹 포함) 탭 막대를 숨긴다. Scaffold는 아래 막대를 키보드 위로 올려 주지 않아 막대가 키보드 뒤에 걸치기 때문이다. 폰 아래 제스처 막대 여백은 `app.dart`의 아래 paper 띠가 처리한다. 탭 글자는 기기 글자 크기를 키워도 1.3배까지만 커진다.
- 안드로이드 앱에서 기기 뒤로 가기는 `AppShell`이 방문 기록으로 처리한다(확인 창이 떠 있으면 창만 먼저 닫힌다).

## 6. 화면별
### 글 목록 `/` (피드형)
```text
  경희대학교                      [전체 학교 ▾]   ← 머리말(30·700) + 학교 드롭다운 (좁으면 아래 줄)
  (✓전체) (잡담) (질문) (학교생활) →             ← 말머리 칩, 가로로 밀림
┌ 판 (paper + line 테두리, 줄 사이 line 선만) ────────┐
│ (선) 선배A [질문] [학교 뱃지]                       │ ← 이니셜 + 닉네임(굵게) + 뱃지
│      비자 연장은 언제부터 신청하나요?              │ ← 제목 16·700, 모든 줄 같은 x에서 시작
│      💬 3  ♥ 5                11월 8일 15:19        │ ← 댓글·공감(아이콘+숫자), 시각은 오른쪽 끝
├────────────────────────────────────────────────────┤
│ (잡) ...                                            │
└────────────────────────────────────────────────────┘
```
- 글은 카드 여러 장이 아니라 **판 하나 안의 행**(선으로 구분). 로딩·에러·빈 목록 문구도 같은 판 안에 보인다. 학교로 거른 화면에선 모두 같은 학교라 학교 뱃지를 뺀다.
- 줄 어디를 눌러도 글로 가고(눌리는 높이 48 이상, hover 바탕으로 조용히 표시), 스크린리더에는 줄 하나가 링크 하나(라벨 순서: 제목, 닉네임, 말머리, 학교, 댓글, 공감, 시각). 왼쪽에 이니셜(36), 닉네임은 굵기·말머리는 색 뱃지·시각은 오른쪽 끝으로 구분한다. 댓글·공감은 아이콘+숫자(스크린리더 "댓글 3"·"공감 4"), 0은 `muted`, 1 이상은 `ink`.
- 말머리 칩(높이 40): 고른 칩은 `ink` 바탕 + 흰 글자 + 체크 + 스크린리더 selected, 안 고른 칩은 `paper` + `fieldBorder` 테두리 + `ink` 글자. 학교는 머리말 오른쪽 드롭다운.
- **연필 버튼**: `highlight` 동그라미(56, 아이콘 `ink`, 툴팁 "글쓰기"(비자 후기는 "후기 쓰기"), 그림자 없음). 본문 기둥 오른쪽 끝(여백 16)에 아래 탭 막대 바로 위로 띄우고, 목록 아래에 88을 비워 마지막 줄이 가려지지 않는다. 비로그인이면 /login으로 보낸다. 스크린리더는 목록보다 먼저 읽는다. 게시판·비자 후기는 항상, 중고는 학교 인증 회원일 때만 보이고(아니면 버튼 없이 `MarketWriteGate` 안내) 인증 회원일 때만 목록 아래를 비운다.
- 공용 위젯(게시판·비자 후기·중고 목록·쪽지함이 쓴다): `FeedRow`(줄 틀: 링크 하나 + 48 이상 + 위 선), `FeedPanel`(피드형 판), `WriteFabLayout`+`writeFabSpace`(연필 버튼 + 아래 여백) — `lib/widgets/`.
- **비자 후기 목록**도 피드형(`FeedRow`+`FeedPanel`)이다: 결과·학교 뱃지 / 제목(16·700) / 접수일 → 결과일 / 작성자와 작성 시각(오른쪽 끝). **이니셜은 넣지 않는다** — 결과 뱃지(승인·불허)가 줄의 첫 요소라 이니셜까지 있으면 눈이 둘로 갈린다. 스크린리더 라벨 순서: 제목, 결과, 학교(학교로 거른 화면은 생략), 작성자, "접수 …", "결과 …", "작성 …"(화면의 화살표 대신 말로 나눈다). 쓰기 버튼은 연필 버튼("후기 쓰기").
- **중고 목록**도 피드형(`FeedRow`+`FeedPanel`)이다: 왼쪽 썸네일(72, 이니셜은 안 쓴다) + 오른쪽에 상태 뱃지 / 제목(16·700, 길면 줄바꿈) / 가격·시각 한 줄(시각은 오른쪽 끝, 한 줄에 안 들어가면 시각이 통째로 다음 줄로) / 학교 이름 한 줄(길면 말줄임). 썸네일을 포함해 줄 어디를 눌러도 상세로 가고 줄 안에 `RowLink`는 없다. 스크린리더 라벨 순서: 제목, 상태, 가격(나눔은 "나눔"), 학교, 시각(썸네일은 장식이라 뺀다). 학교로 거른 화면에서도 학교 이름은 항상 보인다. 판 아래 여백은 인증 회원이면 `writeFabSpace`, 아니면 16(`FeedPanel`엔 바깥 여백이 없어 직접 준다).

### 글 보기·댓글 `/posts/:id`
- 글 판 머리: 이니셜(36) + 닉네임(15·굵게) + 말머리·학교 뱃지, 그 아래 시각(`muted`). 제목 22·700(heading), 본문 15·줄 간격 1.65(드래그로 글자 선택 가능).
- 작업 줄: 공감이 왼쪽 끝, 관리(수정·삭제 또는 신고)가 오른쪽 끝(좁으면 줄바꿈, 신고 양식이 열리면 자기 줄을 한 줄 전체 폭으로 차지). 글의 [수정]·[삭제]·[신고]는 테두리 있는 작은 버튼.
- 댓글 줄: 작은 이니셜(28) + 닉네임(13·굵게) + 시각(`muted`) + 내용. 남의 댓글의 [신고]만 **조용한 버튼**(아래 7장)이고, 열린 신고 양식도 테두리 없이 줄 안에 놓인다(`ReportForm(quiet: true)`). 내 댓글의 [수정]·[삭제]는 테두리 있는 모양. 관리자가 남의 댓글을 볼 때 빨간 [삭제]와 12 떨어져 꼬리표처럼 안 보이게 한다.

### 글쓰기·글 수정 `/posts/new`, `/posts/:id/edit`
- 판 안에 학교 뱃지 + 말머리 상자 줄(세로 중심 정렬), 제목칸, 내용칸(10줄), 버튼 줄이 `space4`(16) 간격으로 같다(두 화면 값 동일). 내용칸 글자는 글 보기 본문과 같은 15·1.65(`postBodyInputStyle`).
- 375px에서 저장·목록으로는 스크롤 끝에서 탭 막대 위에 다 보이고, 키보드가 열리면 탭 막대가 숨고 Scaffold가 본문을 줄여 입력칸·버튼이 안 가려진다.

### 내 정보 `/me`
- 제목 바로 아래 **바로가기 줄**(탭에서 빠진 것): 비자 일정(인증 회원만), 신고 관리·인증 심사(관리자만). 링크가 하나도 없으면 줄 자체를 그리지 않는다. 그 아래 아이디·닉네임 판, 유학생 인증, 닉네임 변경, 비밀번호 변경, 회원 탈퇴(위험색 제목·버튼) 판이 이어진다.
- 인증 뱃지(`accentInk` / `accentSoft`): 학교 인증을 마친 회원 표시(위 막대 "인증", 내 정보 "유학생 인증 완료 · 학교명"). 학교 이름은 툴팁·스크린리더 라벨("인증 (학교 인증 회원)")로 알린다.

### 그 밖 화면
비자 후기·통계·일정, 중고, 챗봇, 쪽지, 관리자, 로그인·가입은 위 토큰과 공용 부품(판·버튼·뱃지·안내)을 그대로 따라가고 배치는 바뀌지 않았다(비자 후기·중고 목록과 쓰기 버튼, 쪽지함 줄은 위 절 참고). 지금도 맞는 개별 규칙:
- **비자 일정 D-n**: 목록 머리말과 같은 30·700. 이 화면의 핵심 숫자라 키운 예외. 색은 평소 `ink`, 확인할 때·긴급(30일 이내)은 `accent`, 지남은 `muted`(빨강 없음). 할 일 목록의 날짜는 마감이 아니라 "확인을 시작할 시점"이라 줄에는 D-n 대신 굵은 칸 "만료 120일 전부터" + 날짜 "2026년 7월 29일"을 쓴다(굵은 칸 최소 폭 8.5em으로 날짜 시작 위치를 맞춘다). 상태는 색 말고 날짜 옆 글자로도 알린다: 지금 단계는 "지금 확인할 때"(굵은 칸·상태 글자 `accent`), 아직 안 온 줄은 "n일 뒤 시작", 지난 줄은 "지난 단계" + `muted`.
- **비자 일정 띠**: 위 막대 바로 아래 한 줄, 로그인한 인증 회원 화면에서만 뜨고 /visa-plan에서는 숨긴다. `infoSoft` 바탕 + `ink` 14px(링크 `accent`), 닫기(×) 눌리는 영역 40, 375px에서 줄바꿈.
- **비자 후기 통계 표**: 판 안, 머리글 `muted` 13, 행 사이 `line`, 숫자 열 오른쪽 정렬, 소수는 항상 1자리("19.0일"). 표만 가로로 밀린다. 링크 탭의 현재 탭은 파랑 밑줄 + 스크린리더 현재 페이지.
- **중고 사진**: 목록 썸네일 72 정사각(cover, 모서리 6). 상세 큰 사진은 폭 100%·4:3 고정 틀(contain, 틀 바탕 `canvas`)이라 비율이 달라도 아래 썸네일 줄이 안 움직인다. 상세 썸네일 56 정사각(cover), 고른 것은 `accent` 테두리. 사진이 없거나 못 불러온 칸은 `hover` 회색, 큰 사진 실패 문구는 틀 안 가운데 `muted` 14. 글쓰기·수정의 사진 올리기: 판 안에 "사진 (n/10)" 제목, 72 미리보기와 아래 작은 버튼(수정 "삭제"·글쓰기 "빼기")을 `space3` 간격으로 줄바꿈하며 나열(375px 가로 스크롤 없음). 진행은 info 안내, 사전 검사·서버 에러는 error 안내, 10장이면 추가 버튼을 비활성하고 옆에 안내.
- **쪽지**: 쪽지함도 피드형(`FeedRow`+`FeedPanel`, 판 아래 여백 16은 직접 준다). 왼쪽 이니셜(36, 탈퇴한 상대는 회색 빈 동그라미) + 오른쪽 세 단: 상대 닉네임(16·700, 말줄임) / 글 제목(`muted`, 지워진 글은 회색 "삭제된 글" 뱃지) / 마지막 쪽지 한 줄(줄임표, 내가 보낸 것은 "나: ") + 그 오른쪽 끝에 시각(`muted`, 한 줄, 마지막 쪽지가 줄어들며 양보). 줄 전체가 링크고 눌림은 hover 바탕. 닉네임 바로 옆 안 읽은 수는 파랑 뱃지(`accentInk` / `accentSoft`, 100 이상 "99+"). 스크린리더 라벨 순서: 닉네임(탈퇴면 "탈퇴한 회원"), "안 읽은 쪽지 N개"(실제 개수, 0이면 생략), "삭제된 글"(해당할 때), 글 제목, 마지막 쪽지, 시각. 대화 말풍선은 내 것이 오른쪽 `accentSoft` + `accentInk`, 상대가 왼쪽 `hover` + `ink`(폭 최대 85%, 모서리 8), 시각은 말풍선 아래 `muted` 13. hasMore면 목록 위에 회색 안내 한 줄. 쓰는 칸은 글자 수("0 / 1000", `muted`)와 주요 버튼.
- **상태·종류 뱃지**(빨강 없음): 승인·판매중·글 신고·쪽지 신고는 파랑(`accentInk` / `accentSoft`, 쪽지 신고는 파랑 글자 + `hover` 바탕), 불허·거래완료·댓글 신고는 회색(`muted` / `badgeChatBg`), 예약중·중고 글 신고는 청록(`badgeQuestion…`).

## 7. 부품
- **버튼 3종**: 주요(`FilledButton`, `ink` 바탕 + 흰 글자, 높이 40, 모서리 6), 보통(`OutlinedButton`, `fieldBorder` 테두리 + `ink` 글자), 글자 버튼(`TextButton`, `accent`). 작은 버튼은 높이 36·좌우 12(`smallButtonStyle`, `smallFilledButtonStyle`). 위험 버튼(`dangerButtonStyle`, 작은 것은 `dangerSmallButtonStyle`): 평소 빨간 글자·선, hover `dangerSoft`, 누르는 동안 `dangerStrong` 바탕 + 흰 글자, 비활성은 반투명.
- **조용한 버튼**(`quietSmallButtonStyle`, 남의 댓글의 [신고]): 테두리 없이 `muted` 13 글자 + 작은 깃발 아이콘(16), 높이 36 이상, 왼쪽 정렬. 마우스를 올리거나 포커스가 오면 `hover` 바탕(포커스는 `accent` 1px 테두리도), 누르면 `line` 바탕. 눌린 공감은 `accentSoft` 바탕·`accent` 선·`accentInk` 글자.
- **입력칸**: 높이 40 이상, 모서리 8, 흰 바탕, 테두리 `fieldBorder`, 포커스 `accent` 1px. 위 라벨이 있는 칸은 `LabeledField`(라벨 14·500, 아래 여백 16). 눈에 보이는 라벨은 스크린리더에서 빼고 입력칸에 이름을 붙인다.
- **뱃지**(`AppBadge`·`CategoryBadge`): 13·500, 좌우 6, 모서리 4. 학교 뱃지는 `paper` + `line` 테두리 + `muted`. 말머리는 잡담 `muted`/`badgeChatBg`, 질문 `badgeQuestionInk`/`badgeQuestionBg`, 학교생활 `highlightInk`/`highlightSoft`(모르는 말머리는 색 없는 뱃지).
- **안내**(`Notice`): 에러 `dangerSoft`+`danger`(alert), 성공 `successSoft`+`successInk`, 정보 `infoSoft`+`ink`(둘은 status). 14·줄 간격 1.5, 모서리 8, 아래 여백 12. 군더더기 안내는 두지 않는다(HTTP 비밀번호 경고, 챗봇 머리 부제, 댓글 못 쓰는 글 안내, 관리자 열람 중 안내, 글쓰기 칸 안 힌트 글자는 지웠다). 같은 조건의 안내가 다른 자리에 이미 있으면 겹쳐 쓰지 않는다.
- **이니셜**(`InitialAvatar`): 닉네임 첫 글자, `highlightSoft` 바탕 + `highlightInk` 글자 한 가지 색(색으로 사람을 구분하지 않는다). 작성자가 없으면 `hover` 빈 동그라미. 크기 36(글 목록·글 머리)/28(댓글), 장식이라 스크린리더가 읽지 않는다.
- **확인 창**(`showConfirm`): 브라우저 기본 창 대신 공용 창. 폭 최대 400, 뒤 막 `backdrop`(눌러도 안 닫힘), 제목 "확인". 왼쪽 "취소"(처음 포커스), 오른쪽은 동작 이름 그대로("삭제", "탈퇴")이고 되돌릴 수 없는 동작이면 위험 버튼. Esc·화면(주소) 바뀜·다른 확인 창이 열리면 취소로 닫힌다.
- 툴팁: `ink` 바탕 + 흰 13px 글자.

## 8. 기본 품질
- 375px 폭에서 가로 스크롤 없음. 버튼·입력칸·칩 높이는 40 안팎(작은 버튼 36), 탭 칸(56)·글 줄(48 이상)은 48 이상.
- 글자 대비 4.5:1 이상(`muted`도 `paper`·`canvas` 위에서 통과).
- 스크린리더: 안내 에러는 alert·정보/성공은 status, 선택·눌림은 Semantics의 selected·toggled(공감, 칩, 탭), 화면 제목은 heading, 버튼·링크에는 읽을 이름을 직접 붙이고 안쪽 아이콘·글자는 `excludeSemantics`로 한 번만 읽게 한다. 이 속성들은 지우지 않는다.
- 입력칸 포커스는 파랑 테두리, 버튼·링크는 Material 기본 포커스 표시.
- 알려진 한계: 글 목록의 연필 버튼은 스크린리더 읽는 순서(sortKey)로는 목록보다 먼저지만, PC 키보드 Tab 순서는 화면에 그려진 순서라 목록 줄들 뒤에 온다. Enter로 줄 열기는 `InkWell` 기본 동작에 맡기고 따로 테스트하지 않았다.
