# 작업 마무리 (인수인계)

이 대화에서 한 일을 바탕으로 docs/handoff.md를 갱신한다. 다른 컴퓨터의 새 세션은 이 파일만 보고 이어서 작업한다.

## 순서
1. 상태 확인: `git status --short`, `git log --oneline -5`, `git status -sb`(push 안 된 커밋 수), docs/backlog.md
2. docs/handoff.md를 아래 형식 그대로 다시 쓴다. 짧게, 다음 사람이 바로 행동할 수 있게.
   - 마지막 갱신: 날짜, 어느 컴퓨터(모르면 생략)
   - 지금 어디까지: 끝난 큰 기능과 단계
   - 다음에 할 일: 바로 다음 행동 한 줄(예: "S3-a build 시작", "planner 결과 승인 대기")
   - 진행 중인 단계: 진행 중인 S번호, 어느 에이전트까지 끝났는지, 승인받은 결정, 커밋 안 된 변경 파일. 없으면 "없음"
   - 주의할 점: 이 대화에서 새로 알게 된 함정이나 환경 메모만 추가하고, 더 이상 맞지 않는 줄은 지운다
3. 사용자에게 보여준다: 바뀐 handoff.md 요약, 커밋 안 된 파일, push 안 된 커밋 수
4. 승인을 받으면 커밋하고 push한다. 커밋 메시지: `chore: 작업 인수인계 갱신` (다른 변경과 같이 커밋할 때는 그 내용을 적는다)
5. Notion 학습 기록(docs/notion-guide.md)이 끝난 단계에 대해 아직 안 쓰였으면 알려준다.

## 쓰지 않는 것
- 서버 IP, 계정 ID, 비밀번호, .env 값
- 대화 전체 요약. 다음 작업에 필요한 것만
